Shell — Slash Commands
/sysinfoFull system enumeration — OS, users, network, processes
/statusSession state, sleep interval and channel info
/sleep <s>Set check-in interval in seconds (1 – 86400)
/jitter <pct>Randomise interval ± pct% (0 – 50)
/download <path>Pull file from target — appears in Artifacts tab
/upload [dest]Push local file to agent; dest defaults to CWD
/timestomp <tgt> <ref>Copy timestamps from ref file onto target file
Persistence
/persist probeProbe all techniques — non-invasive feasibility audit
/persist install <id>Install a persistence technique by ID
/persist remove <id>Remove a persistence technique by ID
/persist status <id>Check current status of a specific technique
/persist checkRe-check all installed techniques
Credential Harvesting
/creds harvestCollect creds — Firefox, SSH, FileZilla, mRemoteNG, PS history, Git, cloud tokens
/creds harvest decryptAlso decrypt Chrome/Edge/DPAPI via CryptUnprotectData (Win)
/creds coerceForce local auth to capture NTLMv2 / SSH agent
/creds samIn-memory SAM hash extraction (Win, SYSTEM or elevated admin)
/creds listen start <proto:port>Start listener — smb:445, http:80 (Basic), http-ntlm:80 (NTLMv2)
/creds listen stop [proto:port]Stop all listeners, or a specific one
/creds listen dumpDump captured credentials + poisoner stats
In-Memory Execution
/bof <file.obj> [args]Execute BOF/COFF object in-memory (Win)
/assembly <file.exe> [args]Execute .NET assembly in-memory via CLR (Win)
/memexec <file.elf> [args]Execute ELF in-memory via memfd_create (Linux)
Lateral Movement — P2P Mesh
/jump <mod> <target> [opts]Spawn P2P child via SMB/WMI/SSH/WinRM — builds & deploys agent
/generate-listener [tcp|smb] [linux|windows]Build standalone P2P listener beacon (manual deploy via USB/phish)
/p2p link tcp <host:port>Connect to a P2P child listening on TCP
/p2p link smb <target-ip> [pipe-name]Connect to a P2P child listening on SMB named pipe (port 445, default pipe: stratum)
/p2p unlink <guid>Disconnect a linked P2P child
/kill-cascadeKill session and all P2P descendants — leaf-first propagation

About Stratum
Stratum C2
v3.0.1 — Cloud Persistence Framework
Dead-drop C2 channel via cloud storage providers.
RSA-4096 + AES-256 encrypted, multi-operator, cross-platform.
📡Provider-agnostic dead-drop — Dropbox, OneDrive, S3, SharePoint, Google Drive and more
🔐RSA-4096 + AES-256 E2E — secrecy, integrity and authenticity enforced at every layer
🕵Zero network footprint — no listening port, no C2 IP, traffic indistinguishable from native cloud app use
⏱Long-run low-footprint payloads — entropy-balanced polling intervals built for sustained deep persistence
🖥Rust ELF stager + bash agent — minimal footprint, zero runtime dependencies
